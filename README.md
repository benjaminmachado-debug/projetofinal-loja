Projeto Final - Loja

Sistema de gerenciamento de uma loja desenvolvido em Java, utilizando conceitos de Programação Orientada a Objetos (POO). O sistema permite cadastrar e gerenciar produtos, realizar operações de venda e consultar informações da loja. Para executar o projeto, é necessário ter o Java JDK instalado e abrir o projeto em uma IDE compatível, como NetBeans, IntelliJ IDEA ou Eclipse, executando a classe principal do sistema.
